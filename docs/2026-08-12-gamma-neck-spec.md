## 1. 役割

マイコンなしの**受動基板**。砲塔側で以下を担う:
1. スリップリング（車体⇔砲塔）のリード線の受け口
2. 24V駆動電源の分配（首モータ3台・P4キャリア）
3. CANバスの分配（CAN1=砲塔系を首モータへ、CAN2=車体系をP4へパススルー）
4. 競技用ゲームモジュール線（4ピン）のパススルー

システム文脈: network_gamma.drawio参照。首=DM3507×2（Roll/Pitch）＋MHF5005（Yaw）の3軸ジンバル、制御はP4キャリア（gamma_turret）のCAN1。

## 3. CAN終端の方針（確定）

- **この基板には終端抵抗を載せない**
- CAN1: **モータ内蔵の切替式終端で運用**（DM3507=内蔵・デフォルトON〔マニュアル確認済み: 「终端电阻开关，默认打开」〕、MHF5005=切替可能〔ユーザー確認〕）。**運用ルール: バス最遠の1台のみON・他はOFF**。デフォルトONのまま3台繋ぐと120Ω×4並列=30Ωで規格外になるため、組立時のスイッチ確認を必須手順とする
- CAN2: 両端終端は車体側とP4キャリア（R9）が担当。この基板は分岐のみ

## 4. 設計上の注意

- 24V大電流経路（スリップリング入力→モータ3分岐＋P4分岐）は太パターン/ベタ。P4分岐はP4のDCDCout経由でESC×2＋サーボの電流も流れる点に注意
- PHの電源ピンは2A/ピン。並列本数×2Aで各口を検算（4.5節・上表に記載済み）。**コネクタ構成はP4向けXT30メスとゲームPA 4Pを除き全てPHファミリーに統一（2026-08-12）**
- 誤挿し対策: P4向けXT30はメス（供給側）で向き分け。PH 8P（DM3507×2）とPA 4Pはピン数で排除
- **⚠️リスク受容（2026-08-12ユーザー判断）**: リング電源入力とMHF5005出力が同じPH 6P — 挿し違えるとモータのCANピンに24V。対策なし・シルク表記＋組立時確認で運用担保
- PH 2P同士（CAN2入力・P4向けCAN1/CAN2）の挿し違えはCAN同士のため実害小（通信不成立のみ・破損なし）

## 4.5 DM3507実測仕様（2026-08-12マニュアル確認済み）

- **電源+CAN端子（SH1.0 8pin）の線序: 1〜3=VCC(24V)並列／4〜6=GND並列／7=CAN_L／8=CAN_H** → PH 8Pへ1対1付け替えでそのまま基板ピン配列になる
- **定格電源電流3.0A・ピーク8.3A/台**（額定0.8Nm・峰値3Nm・減速7:1）
- PH電源容量検算: 3ピン並列×2A=6A ≥ 定格3A → 成立（ピーク8.3Aは瞬時のため許容と判断）
- 終端抵抗: 物理スイッチOFF/ON式・デフォルトON（p3図で確認）
- 注意: マニュアルp2の付属品リストは8pin/3pinの記載が逆（誤記）。p3の接口説明が正: 電源+CAN=8pin、調試串口=3pin
- モータ搭載穴: 4×M3、外径46mm・高37.9mm・150g
